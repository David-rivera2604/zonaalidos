🔐 Manejo de contraseñas de usuarios

¿ Cómo se manejan las contraseñas de los usuarios en el sistema ?

Las contraseñas no se almacenan en texto plano, sino que se protegen mediante un proceso de hashing irreversible utilizando el algoritmo estándar PBKDF2-HMAC-SHA256 con 100,000 iteraciones, cumpliendo con las normativas de seguridad de OWASP y NIST. Para garantizar robustez, cada contraseña se combina con un salt criptográfico único de 256 bits antes del hashing, lo que impide ataques mediante tablas precalculadas (rainbow tables). El resultado final se guarda en la base de datos codificado en Base64 y, durante el inicio de sesión, la validación se realiza mediante una comparación de tiempo constante (SlowEquals) para evitar vulnerabilidades por ataques de canal lateral (timing attacks).

Implementación

Documentación técnica para el componente Architect.Utilities.Helpers.PasswordHasher.

Esta utilidad implementa un hashing de contraseñas seguro, robusto e irreversible, diseñado para cumplir con los estándares modernos de ciberseguridad.

NIST SP 800-132 OWASP ASVS 4.0 FIPS 180-4

Especificaciones del Algoritmo

Característica Valor / Descripción
Funcionalidad Hash PBKDF2 (Password-Based Key Derivation Function 2)
Primitiva Criptográfica HMAC-SHA256
Iteraciones 100,000 (Recomendación OWASP 2023)
Tamaño del Salt 256 bits (32 bytes) - Criptográficamente aleatorio y único por usuario.
Tamaño del Hash 256 bits (32 bytes)

Formato de Almacenamiento

El hash resultante se almacena como una cadena Base64 que concatena el Salt y el Hash derivado.

Formato Binario: [Salt (32 bytes)] + [Hash (32 bytes)]
Formato String: Base64(Array de 64 bytes)

Ejemplo visual: rKfW8x...[64 chars salt]...mQ9pL...[hash]...= (Longitud total: 88 caracteres)

Métodos Principales

1. HashPassword

Genera un hash seguro para una nueva contraseña.

public static string HashPassword(string password)
  • Genera un salt único usando RNGCryptoServiceProvider.
  • Deriva la clave usando PBKDF2 con 100k iteraciones.
  • Retorna la cadena combinada en Base64.

2. VerifyPassword

Valida una contraseña ingresada contra un hash almacenado.

public static bool VerifyPassword(string password, string storedHash)
  • Extrae el salt del hash almacenado.
  • Calcula el hash de la contraseña entrante usando el mismo salt e iteraciones.
  • Utiliza SlowEquals para comparar los resultados.
Protección contra Timing Attacks: La comparación utiliza una implementación de tiempo constante (XOR acumulativo) para evitar que atacantes deduzcan información midiendo el tiempo de respuesta del servidor.

3. NeedsUpgrade

Determina si un hash almacenado debe ser regenerado (útil para migraciones).

public static bool NeedsUpgrade(string storedHash)

Devuelve true si el hash usa un formato antiguo, menos iteraciones de las requeridas o un algoritmo obsoleto.

Ejemplos de Uso

Registro de Usuario

// Al recibir la contraseña del usuario en texto plano
string rawPassword = "UserPassword123!";

// Generar el hash seguro
string secureHash = PasswordHasher.HashPassword(rawPassword);

// Guardar secureHash en la base de datos (columna de al menos 90 chars)
newUser.PasswordHash = secureHash;
_repository.Save(newUser);

Autenticación (Login)

// Recuperar usuario de la BD
var user = _repository.GetByEmail(email);

// Verificar contraseña
bool isAuthenticated = PasswordHasher.VerifyPassword(inputPassword, user.PasswordHash);

if (isAuthenticated)
{
    // Verificar si se requiere migración de seguridad
    if (PasswordHasher.NeedsUpgrade(user.PasswordHash))
    {
        var newHash = PasswordHasher.HashPassword(inputPassword);
        user.PasswordHash = newHash;
        _repository.Update(user);
    }
    // Generar Token / Cookie
}
