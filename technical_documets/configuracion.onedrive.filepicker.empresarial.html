Manual — Configuración de OneDrive File Picker (OneDrive Empresarial)

Qué cubre este manual: habilitar el botón "Adjuntar desde OneDrive" para cuentas de Microsoft 365 / Entra ID (OneDrive for Business), usando MSAL en frontend y OneDrive File Picker v8.
Este documento es para OneDrive empresarial. No usar esta configuración para cuentas personales de Microsoft (MSA).

1. Crear App Registration (organizacional)

  1. Ir a portal.azure.com → Microsoft Entra ID → App registrations → New registration.
  2. Configurar:
    CampoValor recomendado
    NameEjemplo: Aliados-OneDrive-Empresarial.
    Supported account typesAccounts in this organizational directory only (Single tenant) para un solo tenant corporativo.
    Redirect URIPlataforma Single-page application (SPA) y URI del front, por ejemplo https://localhost:44341 (sin slash final).
  3. Guardar el Application (client) ID. Este valor va en OneDriveClientId.

2. Permisos API requeridos

  1. En el App Registration: API permissions → Add a permission.
  2. Agregar permisos delegados:
    • Microsoft Graph: Files.Read (o Files.ReadWrite si aplica).
    • SharePoint (Office 365 SharePoint Online): MyFiles.Read (mínimo para picker de OneDrive del usuario).
  3. Dar Grant admin consent para el tenant.
Si falta permiso de SharePoint, aparecerá AADSTS650057 (Invalid resource) cuando el picker solicite token para recurso SharePoint.

3. Configuración en Web.config

Agregar/validar estas llaves en WebApp/Web.config:

<add key="OneDriveClientId" value="<GUID-DEL-APP-REGISTRATION>" />
<add key="OneDriveAuthority" value="https://login.microsoftonline.com/<TENANT-ID>" />
<add key="OneDrivePickerBaseUrl" value="https://mapfrecorp-my.sharepoint.com/" />

Notas importantes

  • OneDrivePickerBaseUrl debe ser del tenant correcto (por ejemplo mapfrecorp-my.sharepoint.com).
  • Evitar typos de dominio (ejemplo común: maprecorp vs mapfrecorp).
  • Si OneDriveAuthority se deja vacío, el backend hará fallback a EntraId.TenantId.

4. Checklist de validación

  1. El botón Adjuntar desde OneDrive abre el picker.
  2. Autentica con cuenta corporativa (no cuenta personal).
  3. Se puede seleccionar archivo y vuelve al uploader.
  4. El archivo queda en Dropzone y se procesa como adjunto normal.

5. Errores frecuentes y solución rápida

ErrorCausa probableQué corregir
unauthorized_client Authority apunta a consumers o app no organizacional. Usar organizations o tenant específico y registro organizacional.
AADSTS650057 Invalid resource Falta permiso para SharePoint o recurso con dominio incorrecto. Agregar permisos SharePoint + admin consent + revisar OneDrivePickerBaseUrl.
Popup bloqueado Navegador bloquea ventana por falta de gesto de usuario. Iniciar flujo desde click del usuario y evitar bloqueadores de popups.
Recomendación: dejar esta guía junto a la guía de OneDrive personal para diferenciar claramente ambos flujos de autenticación.
